# Generador de Contraseñas Seguras

Un generador de contraseñas que crea contraseñas únicas y seguras para proteger tus cuentas y datos personales. Este proyecto está diseñado para ser fácil de usar y personalizable.

## Características

- Generación de contraseñas seguras y aleatorias.
- Personalización del nivel de seguridad:
  - Longitud de la contraseña (8 - 32).
  - Inclusión de letras mayúsculas, minúsculas, números y caracteres especiales.
- Interfaz simple y amigable.

## Tecnologías utilizadas

- **Lenguaje:** HTML5, CSS3, JavaScript.
