# 🔐 Generador de Contraseñas Seguras  

Un generador de contraseñas que crea claves únicas y seguras para proteger tus cuentas y datos personales. Este proyecto está diseñado para ser fácil de usar, personalizable y adaptable a diferentes niveles de seguridad.  

## 🚀 Características  

✅ **Generación de contraseñas seguras y aleatorias.**  
✅ **Personalización del nivel de seguridad:**  
   - Definir la longitud de la contraseña (entre 8 y 32 caracteres).  
   - Incluir letras mayúsculas, minúsculas, números y caracteres especiales.  
✅ **Interfaz intuitiva y amigable.**  
✅ **Compatible con cualquier navegador moderno.**  

## 🛠️ Tecnologías utilizadas  

📌 **Lenguajes:** HTML5, CSS3, JavaScript.  

## 🎮 Cómo usar el generador  

1. Clona este repositorio en tu máquina local:  
   ```bash
   git clone https://github.com/JuanDP10/PasswordGenerator.git
   ```
2. Abre el archivo `index.html` en tu navegador.  
3. Personaliza la configuración según tus necesidades.  
4. Genera una contraseña segura con un solo clic.
